# CIS-5523-Research-Project
This is my repository for my CIS 5523 Research Project. That involves using Text Mining to classify congressional bills. This repository contains my csv files that I made out of the bill I chose and the code I used to generate &amp; later analyze them with for LDA and KeyBERT. 

P.S: If you want to actually run the code on other bills you need to make sure the virtual enviroment being used has all the KeyBert related libraries installed.
